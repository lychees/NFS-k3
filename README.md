# RETRO RUSH '95 — 3D 街机竞速

用现代 Web 技术复刻 90 年代极品飞车（OpenNFS 复刻对象）的核心体验：街机手感、环形赛道、AI 对手、圈速计时，外加**车库改装**、**涂装拉花**与**氮气加速**。

**在线试玩**：https://lychees.github.io/NFS-k3/

## 玩法

四种单人模式（开始菜单选择，点击或按 1 / 2 / 3 / 4，Enter 进入上次模式）+ 分屏双人（5 或菜单进入，选环道/冲刺）。选定模式后进入**比赛设置**（RACE SETUP）：时间（白天/黄昏/夜晚，键 1/2/3）× 天气（晴/雨，键 4/5），选择记入存档：

- **CIRCUIT 环形赛道**：1.65km 环道跑 3 圈，第 4 位发车，超越 3 名 AI 对手夺冠；圈速/最佳圈计时
- **SPRINT 点对点**：4.36km 山路（落差 ~40m、连续回头弯、更窄路面），一次跑完先到终点者胜；HUD 显示总用时 + 进度百分比 + 里程，每过检查点回复 25% 氮气
- **KNOCKOUT 淘汰赛**：环道上不限圈数，每 **20 秒**淘汰当前最后一名——HUD 常驻显示淘汰倒计时与剩余车数；被淘汰的 AI 自动靠边停车（小地图变灰），剩 2 车时提示 "FINAL DUEL!"；玩家被淘汰即按当时名次结算（第 2/3/4 名），淘汰完全部 3 辆 AI 即为冠军
- **HOT PURSUIT 警察追逐**：冲刺山路上逃脱 **2 辆警车**（黑白涂装 + 车顶红蓝爆闪 + 双音警笛）的追捕，与 3 辆赛车同场竞技，跑到终点且不被逮捕即胜——警车贴近（<3.5m）且你低速（<6 m/s）持续 1.5s 即 **BUSTED**；甩开警车 500m 会在前方 350m 遭遇"增援"；可以撞击警车争取空间（碰撞同样生效）；警车接近时屏幕红边脉冲 + 警笛渐响。逃脱按名次给分，BUSTED 安慰 10 CR
- **2 PLAYERS 分屏双人**（环道/冲刺）：P1 上半屏、P2 下半屏，各自独立追逐相机与 HUD（速度/圈数/名次/氮气条）；AI 对手减为 2 辆保持场上 4 车；先完赛者胜，另一方有 30 秒宽限，超时按里程结算；结算显示 "P1 1st — P2 2nd" 对比（友谊赛不计积分）；双人模式自动关闭 bloom、像素比降为 1 保帧率；淘汰赛与警察追逐不支持双人
- **REPLAY 回放**：所有单人模式自动以 10Hz 录制整场比赛（只保留最近一场，内存存储）；结算界面按 **R** 观看——电视转播相机（6 秒自动轮换跟车，Tab / C 手动切换）、Space 暂停、←/→ 快退快进、1/2/3 变速（0.5×/1×/2×）、Esc 返回结算；淘汰停车、警车、氮气尾焰、刹车灯全部原样重现
- **COCKPIT 驾驶舱视角**：C 键在 追逐 → 引擎盖 → **驾驶舱** 三视角循环（双人同步切换）；车内方向盘（随转向转动）、速度表/转速表指针（转速复用引擎档位模型）、氮气发光存量条、刹车指示灯、A 柱/车顶内衬包围感；相机刚体跟随驾驶位，随车身俯仰侧倾，高速轻微震动；仪表自发光材质在 bloom 下微光
- **天气与昼夜**：白天 / 黄昏（低角度暖光、橙紫天空）/ 夜晚（月光蓝调、大灯增强 + 车头路面光斑、霓虹更亮）；雨天有循环雨粒子、路面反光增强、浓雾阴沉、持续雨声——**湿滑物理**生效（抓地 ×0.75 更易侧滑、刹车力度 ×0.72 刹车距离变长，对全场车辆含 AI 一视同仁）

通用规则：

- 草地会明显减速，护栏外有硬边界 + 减速惩罚
- 手刹（Space）过弯可漂移（带轮胎烟雾）；草地扬尘
- **氮气加速**（Shift / N）：消耗氮气条获得推力爆发，FOV 冲击 + 尾焰 + 速度线 + 相机震动
- 完赛按名次给积分（1st=100 / 2nd=70 / 3rd=50 / 4th=30 CR）
- **两条赛道各自记忆最佳总用时**（存 localStorage），结算时提示"新纪录"，菜单模式项上显示最佳成绩

## 车库（GARAGE）

开始菜单进入（点击 或 按 G），左侧 3D 旋转预览，右侧改装：

- **外观**：8 种车漆、3 种尾翼（无/低尾翼/GT 大尾翼）、3 种轮毂（五辐/网状/大饼）、6 种霓虹底盘灯（含关闭）
- **涂装（LIVERY）**：7 种程序化生成的拉花预设 —— 无涂装 / 双条纹 / 号码圆标 / 双色拼漆 / 格子旗 / 烈焰 / 斜纹；每种可配独立**强调色**（6 色），号码圆标可显示自填**赛车号码（0–99）**。涂装以透明贴片（decal）叠加在主漆之上，不影响玻璃与尾灯
- **性能**（0-5 级，积分购买，逐级 60/90/120/150/180 CR）：
  - 引擎：极速 61→72 m/s，加速 16→24 m/s²
  - 轮胎：抓地 7.5→12，漂移恢复更快，转向更灵敏
  - 氮气瓶：容量 30→100，推力 9→24 m/s²
- **积分**：完赛按名次奖励 1st=100 / 2nd=70 / 3rd=50 / 4th=30 CR
- 积分、改装、外观、涂装、泛光开关均存 localStorage
- AI 车辆每局随机套用外观与涂装方案

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 油门 |
| S / ↓ | 刹车 / 倒车 |
| A D / ← → | 转向 |

## 声音（100% Web Audio 程序合成，无音频素材）

- **引擎声**：车速映射虚拟转速与 5 档自动变速（换挡时转速回落 + 顿挫音），锯齿波 + 次谐波方波经低通滤波；怠速 / 加速 / 滑行音色区分，氮气时音调与滤波同步上扬
- **胎响**：漂移侧滑强度驱动的带通白噪声；**草地**：粗糙低通滚动噪声
- **氮气**：开启瞬间高通扫频嘶声；**碰撞/蹭墙**：低频闷响 + 噪声冲击
- **倒计时**：3-2-1 短促蜂鸣，GO 高亢长音；**结算**：四音胜利音序；**UI**：菜单电子音；**淘汰**：低沉锯齿下行音；**警笛**：LFO 双音交替 wail，音量随最近警车距离衰减
- M 键静音；音量可在车库调节（0–100%），与静音状态一起存入 localStorage
- 遵循浏览器自动播放策略：首次点击/按键时激活 AudioContext；暂停时整体挂起

## 技术栈

- Vite 5 + TypeScript（strict）+ Three.js（含 addons 的 UnrealBloomPass 泛光后处理）
- 无物理引擎：`src/car/carPhysics.ts` 自实现街机车辆模型（纵/侧向速度分解 + 抓地力指数衰减），物理参数按改装配置实例化（`makeTuning`）
- 无外部素材：车辆由挤压轮廓 + BoxGeometry 拼装，涂装/贴图/粒子纹理全部 Canvas 或 shader 程序生成
- 无音频素材：`src/audio/` 全部用 Web Audio API 程序合成（转速/档位/包络为纯函数 `engineModel.ts`）
- 赛道由 Catmull-Rom 样条定义（闭合环道 + 开放点对点共用一套采样/生成代码，数据驱动见 `src/track/trackData.ts`），路面 / 路缘石 / 护栏 / 地形全部程序化生成
- 植被 InstancedMesh；烟雾粒子单 Points 一次 draw call；泛光半分辨率（车库可关）

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # tsc 类型检查 + 生产构建（base = /NFS-k3/）
npm run preview  # 预览构建产物
```

## 部署（GitHub Pages）

仓库已内置 `.github/workflows/deploy.yml`：push 到 `main` 分支后自动执行 `npm ci → npm run build → 部署 dist 到 GitHub Pages`（需在仓库 Settings → Pages 中选择 "GitHub Actions" 作为来源）。生产构建的 `base` 为 `/NFS-k3/`（`vite.config.ts` 按 command 条件设置，开发模式为 `/`），页面地址为 https://lychees.github.io/NFS-k3/ 。

## 代码结构

- `src/track/` — 赛道路线（样条）、路面/地形/天空/植被的程序化生成
- `src/car/` — 车辆模型拼装、涂装贴片（`livery.ts`）、街机物理（调校参数）、Car 实体
- `src/ai/` — AI 对手（赛车线预瞄 + 橡皮筋）
- `src/race/` — 输入、比赛流程（倒计时/圈数/名次）、追逐相机
- `src/garage/` — 存档（localStorage）、车库 DOM 界面、3D 预览场景
- `src/replay/` — 比赛录制（10Hz 环形缓冲）与回放播放（插值 + 转播相机）
- `src/fx/` — 烟雾粒子池、氮气尾焰、速度线、泛光后处理、天气昼夜（`weather.ts` 环境预设/雨粒子）
- `src/audio/` — Web Audio 声音引擎（引擎/胎响/氮气/碰撞/蜂鸣/UI 音）
- `src/ui/` — HUD（含氮气条）、Canvas 小地图、菜单/暂停/结算界面
- `src/main.ts` — 启动与主循环
